Sessions API ​

Query sessions and end users.

GET /api/sessions ​

List sessions with aggregated stats.

  • Auth: Authenticated
  • Rate limit: 120 requests/min per user
  • RBAC: Sessions visible only if all events are in accessible projects

Query Parameters ​

ParamTypeDefaultDescription
searchstring—Substring filter on session ID (case-insensitive)
userIdstring—Filter by end user
limitnumber50Max results (1–200)
offsetnumber0Pagination offset
projectIdstring—Filter by project

Response ​

json
{
  "sessions": [
    {
      "id": "conv-123",
      "userId": "user@example.com",
      "traceCount": 5,
      "eventCount": 12,
      "findingCount": 1,
      "totalCost": 0.045,
      "totalTokens": 3200,
      "topModel": "gpt-4o",
      "firstSeen": "2024-01-15T10:00:00Z",
      "lastSeen": "2024-01-15T10:15:00Z",
      "projectIds": ["proj-001"]
    }
  ],
  "total": 42
}

Example ​

bash
curl -H "Cookie: shv_token=YOUR_TOKEN" \
  "http://localhost:4000/api/sessions?limit=20&offset=0"

GET /api/sessions/:id/events ​

Get all events in a session.

  • Auth: Authenticated
  • Rate limit: 120 requests/min

Response ​

json
[
  {
    "id": "evt-001",
    "traceId": "trace-001",
    "spanId": "span-001",
    "eventType": "span.end",
    "occurredAt": "2024-01-15T10:01:00Z",
    "provider": "openai",
    "model": "gpt-4o",
    "payload": { ... },
    "eventCostUsd": 0.003
  }
]

Events are sorted chronologically.

GET /api/end-users ​

List distinct end users with aggregated stats.

  • Auth: Authenticated
  • Rate limit: 120 requests/min per user
  • RBAC: Non-null project rows are gated; null-project rows visible to all

Query Parameters ​

ParamTypeDefaultDescription
searchstring—Substring filter on user ID (case-insensitive)
limitnumber100Max results (1–500)
offsetnumber0Pagination offset
projectIdstring—Filter by project

Response ​

json
{
  "endUsers": [
    {
      "userId": "user@example.com",
      "projectId": "proj-001",
      "traceCount": 25,
      "totalCost": 0.15,
      "firstSeen": "2024-01-10T08:00:00Z",
      "lastSeen": "2024-01-15T16:00:00Z"
    }
  ],
  "total": 150
}

INFO

The same user appearing in two different projects shows as two separate rows, each with project-specific stats.

Example ​

bash
curl -H "Cookie: shv_token=YOUR_TOKEN" \
  "http://localhost:4000/api/end-users?search=example.com&limit=50"
