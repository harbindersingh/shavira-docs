API Reference ​

The SHAVIRA API is a RESTful JSON API served on port 4000 by default.

Base URL ​

http://localhost:4000

Authentication ​

Most endpoints require authentication via one of two methods:

Session Cookies ​

After login, the API sets HTTP-only cookies:

  • shv_token — access token (8h lifetime)
  • shv_refresh — refresh token (30d lifetime)

Cookies are sent automatically by the browser. For programmatic use, include credentials: "include" in fetch requests.

API Keys ​

For SDK and collector integrations:

Authorization: Bearer shv_your_api_key

API keys use the shv_ prefix and are stored as SHA-256 hashes.

Auth Levels ​

LevelDescription
PublicNo authentication required
AuthenticatedAny logged-in user or valid API key
AdminRequires role: "admin"

Response Format ​

All responses are JSON. Successful responses return the data directly or wrapped in an object:

json
{ "ok": true }
json
{ "sessions": [...], "total": 42 }

Error Format ​

Errors return a JSON object with an error or message field:

json
{ "error": "Validation failed", "details": [...] }

Rate Limiting ​

Endpoint GroupLimit
Login5 attempts per email/IP
Sessions/End Users120 requests/min per user
Exports20 per hour per workspace
SSE Connections5 concurrent per workspace

Workspace Scoping ​

All data queries are automatically scoped to the authenticated user's workspace. You never need to pass a workspace ID — it's inferred from your session or API key.

RBAC ​

  • Admins see all data in the workspace
  • Members see only data in projects they're assigned to, plus workspace-level data (traces without a project)
