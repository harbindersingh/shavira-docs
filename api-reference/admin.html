Admin API ​

Endpoints for workspace administration: user management, pricing, and workspace operations. All endpoints require admin role.

POST /api/admin/users ​

Create a new user in the admin's workspace.

  • Auth: Admin only
  • Audit logged: user.created

Request Body ​

json
{
  "name": "John Doe",
  "email": "john@example.com",
  "role": "member"
}
FieldTypeRequiredDescription
namestringYesFull name
emailstringYesEmail address
rolestringYesadmin or member

Response ​

json
{
  "user": {
    "id": "user-002",
    "name": "John Doe",
    "email": "john@example.com",
    "role": "member"
  },
  "initialPassword": "TempPass123!xyz"
}

Status: 201 Created

The initialPassword is returned once — share it securely with the user. The user must change their password on first login.

Errors: 400 (duplicate email or validation)

POST /api/admin/users/invite ​

Create a user and send an invite email with a temporary password.

  • Auth: Admin only
  • Audit logged: user.invited

Request Body ​

json
{
  "name": "John Doe",
  "email": "john@example.com",
  "role": "member"
}

Response ​

json
{
  "user": {
    "id": "user-002",
    "name": "John Doe",
    "email": "john@example.com",
    "role": "member"
  },
  "initialPassword": "TempPass123!xyz"
}

Status: 201 Created

The operation is transactional — if the email fails to send, the user creation is rolled back.

Errors: 400 (email exists), 500 (email send failure)

DELETE /api/admin/users/:id ​

Delete a user from the workspace.

  • Auth: Admin only
  • Audit logged: user.deleted

Response ​

json
{ "ok": true }

Cascade effects:

  • Removes user from all projects
  • Revokes all API keys
  • Does not delete traces the user created

Guards:

  • Admins cannot delete themselves (returns 400)

Errors: 400 (self-deletion), 404 (user not found)

PATCH /api/admin/users/:id/role ​

Update a user's role.

  • Auth: Admin only
  • Audit logged: user.role_changed

Request Body ​

json
{
  "role": "admin"
}

Response ​

json
{ "ok": true }

GET /api/users ​

List all users in the workspace.

  • Auth: Admin only

Response ​

json
[
  {
    "id": "user-001",
    "name": "Jane Smith",
    "email": "jane@example.com",
    "role": "admin"
  }
]

GET /api/workspaces ​

List all workspaces.

  • Auth: Admin only

Response ​

json
[
  {
    "id": "wrk-001",
    "organization": "Acme Corp",
    "name": "Production",
    "environment": "production"
  }
]

DELETE /api/workspaces/me ​

Delete the current workspace and all data.

  • Auth: Admin only
  • Audit logged: Yes

DANGER

This permanently deletes all workspace data — users, projects, traces, findings, API keys, and cost records. This cannot be undone.

Response ​

json
{ "ok": true }

GET /api/health ​

Health check endpoint. Includes pricing sync status.

  • Auth: Public

Response ​

json
{
  "ok": true,
  "service": "security-ai-agent-api",
  "runtimeModes": ["local-only", "hosted-only", "hybrid"],
  "pricingSync": {
    "lastRunAt": "2026-07-11T02:00:00.000Z",
    "nextRunAt": "2026-07-12T02:00:00.000Z",
    "status": "ok"
  }
}

The pricingSync.status is "ok" when syncs are succeeding, or "failing" after 3 consecutive failures.

GET /api/overview ​

Get full workspace overview data.

  • Auth: Authenticated

Response ​

Returns an EngagementOverview object containing projects, apps, costs, traces, findings, agents, and endpoints for the workspace.

POST /api/runtime/select ​

Select the best model endpoint based on execution mode and capabilities.

  • Auth: Authenticated

Request Body ​

json
{
  "mode": "hybrid",
  "preferredProviders": ["openai", "anthropic"],
  "capabilities": {
    "tools": true,
    "structured_output": false
  }
}
FieldTypeDescription
modestringlocal-only, hosted-only, or hybrid
preferredProvidersstring[]Provider preference order
capabilitiesobjectRequired capabilities

Response ​

json
{
  "endpoint": {
    "id": "ep-001",
    "provider": "openai",
    "model": "gpt-4o",
    "url": "https://api.openai.com/v1",
    "healthy": true
  },
  "reason": "Top-ranked hosted endpoint matching capability requirements"
}

Errors: 400 (validation), 503 (no available endpoint)

POST /api/admin/pricing/sync ​

Create a pricing sync preview. Fetches the latest LiteLLM catalog, diffs against current prices, and returns proposed changes. The preview expires after 15 minutes.

  • Auth: Admin only

Response ​

json
{
  "previewId": "uuid",
  "checkedAt": "2026-07-11T12:00:00.000Z",
  "sourceVersion": "2026-07-11T12:00:00.000Z",
  "changes": [
    {
      "provider": "openai",
      "modelPattern": "gpt-4o",
      "matchType": "exact",
      "old": {
        "inputPerToken": 0.0000025,
        "outputPerToken": 0.00001,
        "pricingVersion": "2026-07-10"
      },
      "next": {
        "inputPerToken": 0.000002,
        "outputPerToken": 0.000008,
        "pricingVersion": "2026-07-11",
        "source": "litellm"
      }
    }
  ],
  "unknown": [
    { "provider": "local", "model": "my-custom-model" }
  ]
}

POST /api/admin/pricing/apply ​

Apply a pricing preview by ID.

  • Auth: Admin only

Request Body ​

json
{
  "previewId": "uuid-from-sync-preview"
}

Response (success) ​

json
{
  "applied": 3,
  "skipped": 0,
  "conflict": false,
  "syncLogId": "uuid"
}

Response (conflict) ​

If upstream prices changed between preview and apply:

json
{
  "applied": 0,
  "skipped": 0,
  "conflict": true,
  "newPreviewId": "uuid",
  "changes": []
}

Errors: 500 (preview not found, expired, or already applied)

POST /api/admin/pricing/custom ​

Add a manual price override for a provider/model combination. Manual prices are never overwritten by the automatic sync.

  • Auth: Admin only

Request Body ​

json
{
  "provider": "local",
  "modelPattern": "my-finetuned-llama",
  "matchType": "exact",
  "inputPerToken": 0.00015,
  "outputPerToken": 0.00022,
  "cachedReadPerToken": null,
  "cachedWritePerToken": null,
  "reasoningPerToken": null,
  "pricingVersion": "custom-2026-07"
}
FieldTypeRequiredDescription
providerstringYesProvider name (normalized)
modelPatternstringYesModel name or pattern
matchTypestringNoexact (default), prefix, or regex
inputPerTokennumberYesCost per input token (USD)
outputPerTokennumberYesCost per output token (USD)
cachedReadPerTokennumberNoCost per cached read token
cachedWritePerTokennumberNoCost per cached write token
reasoningPerTokennumberNoCost per reasoning/thinking token
pricingVersionstringYesVersion tag for this price entry

Response ​

json
{
  "id": "uuid",
  "effectiveFrom": "2026-07-11T12:00:00.000Z"
}

POST /api/admin/pricing/recompute ​

Retroactively recompute costs for historical traces using current pricing. Processes up to 500 rows per call.

  • Auth: Admin only

Request Body ​

json
{
  "from": "2026-07-01T00:00:00Z",
  "to": "2026-07-11T00:00:00Z",
  "projectId": "proj-001"
}
FieldTypeRequiredDescription
fromstringNoStart date (ISO 8601)
tostringNoEnd date (ISO 8601)
projectIdstringNoFilter by project

All fields are optional. Omitting all filters recomputes the 500 oldest rows.

Response ​

json
{
  "rowsUpdated": 142
}
