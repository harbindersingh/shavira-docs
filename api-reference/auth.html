Auth API ​

Authentication endpoints for signup, login, session management, OAuth, and API keys.

POST /auth/signup ​

Create a new user account.

  • Auth: Public

Request Body ​

json
{
  "name": "Jane Smith",
  "email": "jane@example.com",
  "password": "SecurePass123!"
}
FieldTypeRequiredDescription
namestringYesFull name
emailstringYesEmail address
passwordstringYesMin 12 chars, uppercase, number, special char

Response ​

json
{ "message": "Account created", "userId": "user-001" }

Status: 201 Created

Errors: 400 (validation), 409 (email exists)

POST /auth/login ​

Authenticate and create a session.

  • Auth: Public
  • Rate limited: 5 attempts per email/IP

Request Body ​

json
{
  "email": "jane@example.com",
  "password": "SecurePass123!"
}

Response ​

json
{
  "user": {
    "id": "user-001",
    "name": "Jane Smith",
    "email": "jane@example.com",
    "role": "admin",
    "workspaceId": "wrk-001",
    "mustChangePassword": false
  }
}

Sets HTTP-only cookies: shv_token (8h) and shv_refresh (30d).

Errors: 401 (invalid credentials), 403 (email not verified)

GET /auth/me ​

Get the current authenticated user.

  • Auth: Authenticated

Response ​

json
{
  "id": "user-001",
  "name": "Jane Smith",
  "email": "jane@example.com",
  "role": "admin",
  "workspaceId": "wrk-001",
  "pictureUrl": null,
  "mustChangePassword": false
}

POST /auth/refresh ​

Refresh the access token using the refresh cookie.

  • Auth: Public (uses shv_refresh cookie)

Response ​

json
{ "ok": true }

Sets a new shv_token cookie.

Errors: 401 (invalid/expired refresh token)

POST /auth/logout ​

Sign out and invalidate all tokens.

  • Auth: Authenticated

Response ​

json
{ "ok": true }

Clears both shv_token and shv_refresh cookies and invalidates all refresh tokens for the user.

GET /auth/verify-email ​

Verify email address with a token from the signup email.

  • Auth: Public

Query Parameters ​

ParamTypeDescription
tokenstringVerification token from email

Response ​

json
{ "ok": true, "message": "Email verified — you can now log in" }

Errors: 400 (invalid/expired token)

POST /auth/forgot-password ​

Request a password reset email.

  • Auth: Public

Request Body ​

json
{
  "email": "jane@example.com"
}

Response ​

json
{ "ok": true, "message": "If an account exists, a reset link has been sent" }

Always returns the same response to prevent user enumeration. Reset links expire after 1 hour.

POST /auth/reset-password ​

Reset password with a token from the reset email.

  • Auth: Public

Request Body ​

json
{
  "token": "reset-token-from-email",
  "password": "NewSecurePass456!"
}

Response ​

json
{ "ok": true, "message": "Password updated — please log in" }

POST /auth/change-required-password ​

Change password when mustChangePassword is true (invited users).

  • Auth: Authenticated

Request Body ​

json
{
  "newPassword": "MyNewSecurePass789!"
}

Response ​

json
{ "ok": true }

Errors: 400 (not required, or validation failed)

GET /auth/google ​

Initiate Google OAuth flow.

  • Auth: Public
  • Response: Redirect to Google OAuth consent screen

Only available when GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET are configured.

GET /auth/google/callback ​

Google OAuth callback handler.

  • Auth: Public
  • Response: Redirect to app with session established

Creates a new account if one doesn't exist with the Google email. Links to an existing account if the email matches.

GET /auth/keys ​

List API keys for the workspace.

  • Auth: Authenticated

Response ​

json
[
  {
    "id": "key-001",
    "name": "production-chatbot",
    "createdAt": "2024-01-10T00:00:00Z",
    "projectId": "proj-001",
    "lastUsedAt": "2024-01-15T10:00:00Z",
    "revoked": false
  }
]

POST /auth/keys ​

Create a new API key.

  • Auth: Authenticated
  • Audit logged: api_key.created

Request Body ​

json
{
  "name": "production-chatbot",
  "projectId": "proj-001"
}
FieldTypeRequiredDescription
namestringYesDescriptive key name
projectIdstringNoScope to a project

Response ​

json
{
  "id": "key-001",
  "name": "production-chatbot",
  "key": "shv_a1b2c3d4e5f6...",
  "projectId": "proj-001",
  "createdAt": "2024-01-15T10:30:00Z",
  "revoked": false
}

Status: 201 Created

WARNING

The key field is returned only once. Copy it immediately — it cannot be retrieved later.

DELETE /auth/keys/:id ​

Revoke an API key.

  • Auth: Authenticated
  • Audit logged: api_key.revoked

Response ​

json
{ "ok": true }

Errors: 404 (key not found)
