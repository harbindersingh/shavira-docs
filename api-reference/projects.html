Projects API ​

Manage projects, members, and archive lifecycle.

GET /api/v2/projects ​

List all non-deleted projects in the workspace.

  • Auth: Authenticated

Response ​

json
[
  {
    "id": "proj-001",
    "name": "Production Chatbot",
    "slug": "production-chatbot",
    "environment": "production",
    "summary": "Main customer-facing AI chatbot",
    "archivedAt": null,
    "archivedBy": null,
    "deleteAfter": null,
    "createdAt": "2024-01-01T00:00:00Z",
    "updatedAt": "2024-01-15T10:00:00Z"
  }
]

Projects are ordered: active first, then archived, alphabetically by name.

POST /api/v2/projects ​

Create a new project.

  • Auth: Admin only
  • Audit logged: project.created

Request Body ​

json
{
  "name": "Production Chatbot"
}

Response ​

json
{
  "id": "proj-002",
  "name": "Production Chatbot",
  "slug": "production-chatbot",
  "createdAt": "2024-01-15T10:30:00Z"
}

Status: 201 Created

PATCH /api/v2/projects/:id ​

Rename a project.

  • Auth: Admin only
  • Audit logged: project.renamed

Request Body ​

json
{
  "name": "New Project Name"
}

Renaming also regenerates the slug. Archived projects cannot be renamed (returns 400).

POST /api/v2/projects/:id/archive ​

Archive a project.

  • Auth: Admin only
  • Audit logged: project.archived

Sets archived_at, archived_by, and delete_after (30 days from now). After the deletion window, an automated process permanently removes all project data.

Response ​

Returns the updated project with archive metadata.

POST /api/v2/projects/:id/restore ​

Restore an archived project.

  • Auth: Admin only
  • Audit logged: project.restored

Clears archive metadata and resets the deletion timer. Returns 400 if the project is not archived.

GET /api/v2/projects/:id/members ​

List project members.

  • Auth: Authenticated

Response ​

json
[
  {
    "projectId": "proj-001",
    "userId": "user-001",
    "name": "Jane Smith",
    "email": "jane@example.com",
    "role": "member",
    "grantedAt": "2024-01-10T00:00:00Z"
  }
]

POST /api/v2/projects/:id/members ​

Add a user to a project.

  • Auth: Admin only
  • Audit logged: project_member.added

Request Body ​

json
{
  "userId": "user-001",
  "role": "member"
}

PATCH /api/v2/projects/:id/members/:userId ​

Update a member's project role.

  • Auth: Admin only
  • Audit logged: project_member.role_changed

Request Body ​

json
{
  "role": "admin"
}

DELETE /api/v2/projects/:id/members/:userId ​

Remove a user from a project.

  • Auth: Admin only
  • Audit logged: project_member.removed

GET /api/v2/users/:id/projects ​

List all workspace projects with membership flag for a specific user.

  • Auth: Admin only

Response ​

json
[
  {
    "projectId": "proj-001",
    "projectName": "Production Chatbot",
    "isMember": true,
    "role": "member"
  },
  {
    "projectId": "proj-002",
    "projectName": "Staging Agent",
    "isMember": false,
    "role": null
  }
]

INFO

This endpoint is scoped to the querying admin's workspace. Querying a user ID from another workspace returns the admin's own workspace projects with isMember: false.

POST /api/v2/projects/:id/dismiss-banner ​

Dismiss the archive warning banner.

  • Auth: Authenticated (must be a project member)
  • Audit logged: banner.dismissed

Request Body ​

json
{
  "view": "members"
}

GET /api/v2/projects/:id/banner-dismissed ​

Check banner dismissal status.

  • Auth: Authenticated (must be a project member)

Response ​

json
{
  "isDismissed": true,
  "warningEmailSent": false
}

Dismissals are archive-cycle-aware: restoring and re-archiving a project resets the dismissal.
