WHY SHAVIRA

Observability built for the way agents actually fail.

Traditional APM sees HTTP calls. SHAVIRA sees prompts, tools, plans and the security events hidden inside them.

Trace everything

Every LLM call, tool invocation and agent step as a structured trace. TypeScript, Python and OpenTelemetry SDKs.

Security intelligence

Sigma-based detection rules, MITRE ATT&CK mapping, and finding workflows with status tracking and assignments.

Self-hostable

One docker compose up. PostgreSQL storage, no external dependencies — your data never leaves your infrastructure.

Real-time streaming

Server-Sent Events push new traces to your dashboard the instant they land. A live indicator shows connection status.

Multi-project

Organise traces by project with RBAC, per-project API keys and workspace isolation for team environments.

Cost attribution

Automatic cost per trace with verified, estimated and reported tiers. Roll-ups per project so finance stops guessing.

HOW IT WORKS

Instrument. Detect. Respond.

1

Instrument your agent

Drop in the SDK or point your OpenTelemetry exporter at SHAVIRA. Every call becomes a structured span.

2

Detect with Sigma rules

Detection rules run against the stream and map hits to MITRE ATT&CK techniques, raising findings in real time.

3

Respond and track

Assign findings, move them through status, and close the loop — with the full trace attached as evidence.

THE PRODUCT

From raw spans to a closed finding.

SECURITY INTELLIGENCE

Findings, not just logs.

A suspicious tool call shouldn't sit in a log file until the post-mortem. SHAVIRA turns it into a finding with a severity, an owner and a status — and keeps the trace attached as evidence.

  • Sigma rule engine with a bundled rule set
  • MITRE ATT&CK technique mapping on every finding
  • Status workflow with assignments, comments and bulk actions

SDKS

Minutes to first trace.

Native SDKs for TypeScript and Python, or send spans from anything that speaks OpenTelemetry.

Read the SDK docs →
agent.ts
// npm install @shavira/sdk
import { SecurityAgentSdk } from '@shavira/sdk'

const sdk = new SecurityAgentSdk({
  baseUrl: 'https://shavira.yourcompany.com',
  apiKey: process.env.SECURITY_SDK_API_KEY,
})

const trace = sdk.trace('unique-trace-id')
await trace.start({ name: 'chat-flow', service_name: 'my-ai-app' })

await trace.spanStart('span-1', { name: 'llm-call', provider: 'openai', model: 'gpt-4o' })
await trace.spanEnd('span-1', { input_tokens: 150, output_tokens: 80 })
await trace.cost({ provider: 'openai', model: 'gpt-4o', input_tokens: 150, output_tokens: 80 })
