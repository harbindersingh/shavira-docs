Real-time Streaming ​

SHAVIRA pushes new traces and findings to your dashboard in real time using Server-Sent Events (SSE).

How It Works ​

When you open the Traces view, the browser establishes an SSE connection to GET /api/traces/stream. New traces and findings appear instantly without refreshing.

Live Indicator ​

A pulsing green dot in the toolbar indicates an active SSE connection. If the connection drops, the indicator turns gray and the client automatically reconnects.

Event Types ​

The stream emits two event types:

EventDescription
trace.newA new trace was ingested
finding.newA new security finding was created

Connection Limits ​

Each workspace supports up to 5 concurrent SSE connections. Additional connections are rejected with a 429 status. Close unused browser tabs to free up connections.

Keepalive ​

The server sends a heartbeat comment every 30 seconds to keep the connection alive through proxies and load balancers.

Project Filtering ​

Add a projectId query parameter to filter the stream to a specific project:

GET /api/traces/stream?projectId=proj-001

Without this parameter, you receive all events for your workspace.

Programmatic Access ​

You can consume the SSE stream from any HTTP client:

bash
curl -N -H "Cookie: shv_token=YOUR_TOKEN" \
  http://localhost:4000/api/traces/stream
javascript
const events = new EventSource('/api/traces/stream', {
  withCredentials: true,
})

events.addEventListener('message', (e) => {
  const data = JSON.parse(e.data)
  console.log(data.type, data.data)
})

Trace Highlighting ​

Newly received traces are highlighted in the table for a few seconds so you can spot them easily. The highlight fades automatically.
