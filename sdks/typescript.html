TypeScript SDK ​

The TypeScript SDK provides a lightweight client for sending traces to SHAVIRA from Node.js and TypeScript applications.

Installation ​

bash
npm install @security-ai-agent/sdk

Quick Start ​

typescript
import { SecurityAgentSdk } from '@security-ai-agent/sdk'

const sdk = new SecurityAgentSdk({
  baseUrl: 'http://localhost:4000',
  apiKey: 'shv_your_api_key', // optional
})

const trace = sdk.trace('unique-trace-id')

// Start a trace
await trace.start({
  name: 'chat-flow',
  environment: 'production',
  service_name: 'my-ai-app',
})

// Record a span
await trace.spanStart('span-1', {
  name: 'llm-call',
  provider: 'openai',
  model: 'gpt-4o',
})

await trace.spanEnd('span-1', {
  output: 'Response from the model',
  input_tokens: 150,
  output_tokens: 80,
})

// Record cost
await trace.cost({
  provider: 'openai',
  model: 'gpt-4o',
  input_tokens: 150,
  output_tokens: 80,
})

Configuration ​

typescript
const sdk = new SecurityAgentSdk({
  baseUrl: 'http://localhost:4000',  // Required: SHAVIRA API URL
  apiKey: 'shv_your_api_key',       // Optional: API key for auth
  fetcher: customFetch,              // Optional: custom fetch implementation
})
OptionTypeRequiredDescription
baseUrlstringYesSHAVIRA API base URL
apiKeystringNoAPI key (prefix: shv_)
fetchertypeof fetchNoCustom fetch function

API Reference ​

sdk.trace(traceId) ​

Returns a trace builder with the following methods:

MethodDescription
start(payload)Emit a trace.start event
spanStart(spanId, payload)Emit a span.start event
spanEnd(spanId, payload)Emit a span.end event
event(payload)Emit a generic event.create event
cost(payload)Emit a cost.record event

Direct Methods ​

MethodDescription
sdk.traceStart(traceId, payload)Direct trace start
sdk.createEvent(traceId, payload)Direct event creation
sdk.recordCost(traceId, payload)Direct cost recording
sdk.ingest(event)Raw event ingest

All methods return Promise<Response>.

Runtime Identity ​

Standardize these fields across all services for consistent filtering:

typescript
await trace.start({
  service_name: 'case-summarizer',    // Logical service name
  environment: 'production',          // Deployment environment
  instance_id: 'pod-abc-123',         // Unique instance identifier
})

Recommended Naming ​

FieldExamples
service_nameai-chatbot, incident-agent, case-summarizer
environmentlocal, staging, prod, customer-a-prod
instance_idhostname + PID, container ID, ECS task ID

Session and User Tracking ​

typescript
await trace.start({
  sessionId: 'conv-abc-123',       // Groups multi-turn traces
  userId: 'user@example.com',      // End user identity
  // ...
})

Best Practices ​

  • Emit from the backend — sensitive prompts, stable credentials, and container runtime identity make backend emission preferred
  • Use consistent service names — the same service should always use the same service_name across deployments
  • Include session IDs — enable multi-turn conversation tracking
  • Set user IDs — enable per-user analytics and security monitoring
