Send Your First Trace ​

This guide walks you through sending your first trace to SHAVIRA using the Python SDK.

Prerequisites ​

  • SHAVIRA running locally (Docker Setup)
  • Python 3.9+

Install the SDK ​

bash
pip install -e packages/python-sdk

Configure Environment ​

bash
export SECURITY_SDK_ENABLED=true
export SECURITY_SDK_BASE_URL=http://localhost:4000
export RUNTIME_ENVIRONMENT=local
export SERVICE_NAME=my-first-app

Send a Trace ​

python
from securitysdk import SecurityTelemetry

telemetry = SecurityTelemetry.from_env(service_name="my-first-app")

# Send a startup trace to verify connectivity
result = telemetry.emit_startup_trace(route="/startup")
print(result)  # Should print the API response

Instrument a FastAPI Route ​

python
from fastapi import Depends, FastAPI, Request
from securitysdk import SecurityTelemetry, observe_route

app = FastAPI()
telemetry = SecurityTelemetry.from_env(service_name="my-first-app")


def extract_user(request: Request) -> str:
    request.state.security_user_id = "user@example.com"
    request.state.security_metadata = {
        "provider": "openai",
        "model": "gpt-4o",
        "agent_model": "gpt-4o",
    }
    return request.headers.get("authorization", "")


@app.post("/chat")
@observe_route(telemetry, trace_name="chat-flow")
async def chat(body: dict, request: Request, token: str = Depends(extract_user)):
    # Your LLM logic here
    return {"response": "Hello from SHAVIRA!"}

Using the TypeScript SDK ​

typescript
import { SecurityAgentSdk } from '@security-ai-agent/sdk'

const sdk = new SecurityAgentSdk({
  baseUrl: 'http://localhost:4000',
})

const trace = sdk.trace('my-first-trace')

// Start a trace
await trace.start({
  name: 'chat-flow',
  environment: 'local',
  service_name: 'my-ts-app',
})

// Record an event
await trace.event({
  type: 'llm.call',
  provider: 'openai',
  model: 'gpt-4o',
  input: 'Hello, world!',
  output: 'Hi there!',
})

// Record cost
await trace.cost({
  provider: 'openai',
  model: 'gpt-4o',
  input_tokens: 10,
  output_tokens: 20,
})

Verify in the UI ​

  1. Open http://localhost:4173
  2. Navigate to Traces
  3. Your trace should appear with the service name and environment you configured
  4. Click on a trace row to inspect its metadata, spans, and cost information

What SHAVIRA Captures Automatically ​

With the SDK configured, SHAVIRA auto-infers:

  • Route path — from the HTTP request
  • Input payload — prompt or request body
  • Runtime identity — service name, environment, instance ID
  • User identity — from security_user_id
  • Latency — measured by the SDK
  • Cost — resolved in priority order: verified > estimated > reported > unknown
